# Personal Halloween Map

Personal site: https://josephwbuchanan.github.io/Halloween-Map/
Personal database: zskwzqzmmymhdwfcmugw

Arrowbrooke source GitHub and Supabase are read only. This site refreshes approved neighborhood homes one way into its own database every five minutes while open, plus the Refresh homes button. Personal additions are preserved. Failed or incomplete upstream snapshots retain the saved mirror; unusually large removals are held for safety.

Start our night joins one shared crew for this personal link for the current Central-time date. Precise routes are restricted to joined crew members. People with this link can join, so share it only with trusted people. Viewing the map alone does not record GPS. Permission and Start/Resume are required. Pause is per phone and Resume uses a fresh run ID, without bridging the detour. GPS recording in a browser is not reliable in the background or with the screen locked.

Tracking allows golf-cart speeds through 30 mph with a GPS noise margin up to 40 mph. Gaps over 20 seconds, jumps over 350 metres and implausible speeds are not joined. Streets are snapped within 35 metres and routed on cached existing map tile geometry; there is no off-street straight-line fallback. Roads absent from the loaded/cached tiles cannot be painted until loaded. Street names stay above the black road line.

Developer login, messages, notifications and neighborhood analytics remain disabled on this copy. The Pages site and source code remain public; an unshared link is not access control. Old personal source is in Git history; old personal tables are privately archived in personal_legacy_20261031. No passwords or push subscriptions were copied.
